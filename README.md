# Chat Reply Metrics

在 DeepSeek Harness 聊天输入框下方显示最近一次已完成模型调用的预估美元费用。插件只读取会话已有记录，不发送额外请求，也不在回复正文下添加指标。适配 DSH `0.2.2-rc.5`。

## 安装与使用

1. 将仓库克隆或下载到本地，在 DSH 插件管理页选择「添加插件」，指定包含 `package.json` 的仓库根目录。
2. 打开有模型调用记录的会话，在输入框下方查看金额。仓库包含[预构建客户端](client.js)，安装时不需要运行构建命令。

| 底部显示 | 含义 |
| --- | --- |
| `≈ $0.0766` | 最近一次已完成调用约花费 0.0766 美元。一次对话可能包含多次调用，这不是整轮或会话合计。 |
| `费用未知` | 已有调用记录，但模型没有匹配费率，或用量缺失、无法核对。未知不等于免费。 |
| 不显示金额 | 当前会话还没有可读取的已完成调用。 |

## 费用从哪里来？

插件按请求轨迹记录的模型 ID 精确查[静态费率表](data/rates.json)，同一模型跨服务商使用相同单价，无需为每个 provider 重复配置，分别计算普通输入、缓存读取、缓存写入和输出费用。费率单位为美元 / 百万 Token。这是估算，不是服务商账单；插件不会联网查询价格，也不会在运行时读取本机 Pi 配置。

## 开发与验证

修改[界面组件](src/client.js)、[计费逻辑](src/metrics.js)或费率表后，运行：

```sh
npm test
npm run build
```

将重新生成的根目录 `client.js` 与源码一起提交。要在干净检出上复现 GitHub 的检查，运行 `npm run check`：它会测试、重新构建，并检查产物是否与 Git 一致。维护约定见 [AGENTS.md](AGENTS.md)。
