# Chat Reply Metrics

DeepSeek Harness 插件：在聊天输入框下方显示最近一次已完成模型调用的预估美元费用。它不修改聊天正文，也不发送额外的模型请求。当前适配 DSH `0.2.2-rc.5`。

## 安装

在 DSH 的插件管理页选择「添加插件」，指定本仓库目录。仓库包含预构建的客户端入口，直接使用无需安装开发依赖。

## 开发

```sh
npm test
npm run build
```

- `src/client.js`：底部费用组件及插槽注册。
- `src/metrics.js`：选择已完成调用，并按模型和用量计算费用。
- `data/rates.json`：静态费率，单位为美元 / 百万 Token。更新后需重新构建；运行时不会读取本机 Pi 配置。
- `scripts/build.mjs`：将组件、计算函数和费率打包为根目录的 `client.js`。请编辑源码并提交重新构建的产物，不要直接编辑产物。
- `tests/`：调用选择和计费规则测试。
- `locale/`：插件管理页的中英文描述。

金额不是账单或整轮费用。没有调用记录时不显示；无法匹配费率或缺少必要用量时显示「费用未知」。
