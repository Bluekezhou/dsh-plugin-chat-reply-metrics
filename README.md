# DSH Chat Reply Metrics

在 DeepSeek Harness 聊天输入框下方显示最近一次已完成模型请求的预估费用（「上次」），以及当前会话和递归子代理的累计预估费用（「总消费」）。没有可计价数据时（空会话、统计读取失败或调用全部无法计价）底部不显示任何内容。点击累计金额可查看当前会话或所有会话的历史估算。查询不会额外调用模型，也不会在回复正文下添加指标。适配 DSH `0.2.2-rc.5`。

## 安装与使用

1. 将仓库克隆或下载到本地，在 DSH 插件管理页选择「添加插件」，指定包含 `package.json` 的仓库根目录。
2. 打开有模型调用记录的会话，在输入框下方查看金额。仓库包含[预构建客户端](client.js)，安装时不需要运行构建命令。

| 底部显示 | 含义 |
| --- | --- |
| `总消费 ≈ $0.0766` | 当前会话及其子代理的累计估算，与明细合计口径相同。 |
| `已知小计` | 部分调用无法计价或部分会话不可读取，只显示已知金额。 |

「上次」只在该次调用可按费率表计价时出现；会话内没有已计价调用时，底部入口整体隐藏。

## 会话与全局消耗

输入框下方的「消耗明细」入口在会话存在已计价调用后出现；空会话或所有调用都无法计价时不显示入口。默认显示当前会话自身、递归子代理、两者合计和按模型明细；切换「所有会话」查看当前 DSH 宿主持久化记录的汇总。刷新可读取新完成的调用。查看入口仅允许宿主所有者读取。普通分叉独立统计，不重复计入继承的历史记录；有模型调用证据的压缩摘要也计入。无法计价的调用列出次数，不算作零美元；无法读取的会话会单独提示。

## 飞书日报（默认关闭）

先在「DSH 飞书会话」绑定并验证你的机器人私聊，再在本插件的配置中把 `dailyEnabled` 设为 `true`。`dailyTime` 默认 `09:00`，`dailyTimeZone` 默认 `Asia/Shanghai`。日报统计该时区前一自然日的全部会话，用同一套模型费率，只发给已绑定的所有者，不含提示词、会话标题或正文。无需在本插件重复填写 App Secret。宿主须运行，停机多日不逐日补发。飞书不可用不影响网页查询。

## 费用从哪里来？

插件按请求轨迹记录的模型 ID 查[静态费率表](data/rates.json)：先精确匹配；带自定义 provider 前缀的 ID（如 `anthropic-kimi-k3`）按连字符边界取费率表中最长的后缀匹配，无需为每个 provider 前缀重复配置。同一模型跨服务商使用相同单价，分别计算普通输入、缓存读取、缓存写入和输出费用。费率单位为美元 / 百万 Token。这是估算，不是服务商账单；插件不会联网查询价格，也不会在运行时读取本机 Pi 配置。

## 开发与验证

修改[界面组件](src/client.js)、[计费逻辑](src/metrics.js)或费率表后，运行：

```sh
npm test
npm run build
```

将重新生成的根目录 `client.js` 与源码一起提交。要在干净检出上复现 GitHub 的检查，运行 `npm run check`：它会测试、重新构建，并检查产物是否与 Git 一致。维护约定见 [AGENTS.md](AGENTS.md)。
